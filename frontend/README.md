# API Documentation Generator - Frontend

Next.js frontend for the API Documentation Generator.

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Environment Variables

Create a `.env.local` file:

```
NEXT_PUBLIC_API_URL=http://localhost:8000/api
```

## Build

```bash
npm run build
npm start
```

## Deployment

Deploy to Vercel:

```bash
vercel
```

Set the environment variable `NEXT_PUBLIC_API_URL` to your backend URL in Vercel dashboard.
